# 同步代理实例接口

## 基本信息

| 项目           | 说明                     |
|--------------|------------------------|
| 接口地址         | `/api/instance/sync`   |
| 请求方式         | `POST`                 |
| Content-Type | `application/json`     |
| 返回格式         | `application/json`     |

## 请求参数

请求体为 **JSON 数组**，每个元素为一个代理实例编号。

### 请求体字段

| 参数名 | 类型       | 必填 | 说明               |
|-----|----------|:--:|------------------|
| —   | String[] | ✅  | 代理实例编号数组，至少传入一个  |

### 请求示例

```json
[
    "c_gz3h2igp6dz9cq3",
    "c_gjhfpkxyqjx2n76"
]
```

> 支持批量同步，数组中可传入多个实例编号。接口会从第三方拉取这些实例的最新数据并更新到本地数据库。

## 返回数据

### 成功响应

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "expectedCount": 2,
        "actualCount": 2
    }
}
```

### 通用响应结构

| 字段      | 类型      | 说明                           |
|---------|---------|:-----------------------------|
| code    | Integer | 状态码：200=成功，400=参数错误，500=系统错误 |
| message | String  | 提示信息                         |
| data    | Object  | 同步结果数据                       |

### data 字段说明（ProxyInstanceSyncResultVO）

| 字段            | 类型      | 说明                                    |
|---------------|---------|:--------------------------------------|
| expectedCount | Integer | 预期更新数（第三方返回的实例数量）                      |
| actualCount   | Integer | 实际更新数（数据库实际影响行数）                       |

> 当 `expectedCount` 与 `actualCount` 不一致时，说明部分实例在本地库中不存在（WHERE instance_no 匹配不到），数据未写入。

## 错误响应示例

### 请求体为空（code: 500）

```json
{
    "code": 500,
    "message": "同步失败：请求体不能为空",
    "data": null
}
```

### 同步失败-第三方API异常（code: 500）

```json
{
    "code": 500,
    "message": "同步失败：获取实例信息API错误: invalid signature",
    "data": null
}
```

### 同步失败-数据库写入异常（code: 500）

```json
{
    "code": 500,
    "message": "同步失败：批量更新代理实例异常",
    "data": null
}
```
