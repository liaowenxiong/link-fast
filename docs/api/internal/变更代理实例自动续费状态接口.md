# 变更代理实例自动续费状态接口

## 基本信息

| 项目           | 说明                           |
|--------------|------------------------------|
| 接口地址         | `/api/instance/{instanceNo}` |
| 请求方式         | `PATCH`                      |
| Content-Type | `application/json`           |
| 返回格式         | `application/json`           |

## 路径参数

| 参数名        | 类型     | 必填 | 说明     |
|------------|--------|:--:|--------|
| instanceNo | String | ✅  | 代理实例编号 |

## 请求参数

### 请求体字段

| 参数名   | 类型      | 必填 | 说明               |
|-------|---------|:--:|------------------|
| renew | Integer | ✅  | 自动续费状态：0=关闭，1=开启 |

### 请求示例

开启自动续费：

```json
{
    "renew": 1
}
```

关闭自动续费：

```json
{
    "renew": 0
}
```

## 返回数据

### 成功响应

```json
{
    "code": 200,
    "message": "设置成功",
    "data": null
}
```

### 通用响应结构

| 字段      | 类型      | 说明                           |
|---------|---------|:-----------------------------|
| code    | Integer | 状态码：200=成功，400=参数错误，500=系统错误 |
| message | String  | 提示信息                         |
| data    | Object  | 固定为 null                     |

## 错误响应示例

### 参数校验失败-renew 为空（code: 400）

```json
{
    "code": 400,
    "message": "参数校验失败: renew: 自动续费状态renew不能为空",
    "data": null
}
```

### 参数校验失败-renew 超范围（code: 400）

```json
{
    "code": 400,
    "message": "参数校验失败: renew: 自动续费状态renew只允许0或1",
    "data": null
}
```

### 实例不存在（code: 400）

```json
{
    "code": 400,
    "message": "实例不存在: c_gjhfpkxyqjx2n76",
    "data": null
}
```
